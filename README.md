# transformers-desde-cero-pytorch
Implementación pedagógica de un Transformer codificador-decodificador desde cero con PyTorch. Incluye atención escalada, multi-cabeza, codificación posicional, conexiones residuales, normalización y atención cruzada. Explica los siete mecanismos de la IA generativa, con código comentado y cuaderno Jupyter listo para Colab.
